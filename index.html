NEXUS Tube configuration

NEXUS Tube is configured by the site owner. Visitors do not need to enter their own YouTube API key. The site owner must add a YouTube Data API v3 key in the configuration line near the bottom of this file.

For safety, restrict the key in Google Cloud Console to YouTube Data API v3 and the exact GitHub Pages website referrer. A browser-based key is visible to visitors who inspect the page; referrer restrictions reduce misuse but do not make it secret. A personalized YouTube FYP is not available through this public API.
